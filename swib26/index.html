SWIB26 workshop

Learning entity-oriented metadata with EntEdit

The future of library data is entity-based, and the new generation of librarians must be trained in the mindset, formats, vocabularies and identifiers that will be the core of library data. In education we lack convenient and pedagogically oriented tools that students can use to build knowledge of, reflect on and gain experience with bibliographic entities. This workshop presents EntEdit, an entity-oriented editor made for that purpose, and lets you try it out on a set of learning activities.

EntEdit

EntEdit is an entity-oriented editor where students create entities, give them attributes and relate them to each other. They can explore the structures they build in visualizations, see how the data behaves in a bibliographic search, and download it as RDF (Turtle), for example to share their work or hand in an assignment. The editor can also log what users do, to learn how students build their set of entities.

It is a web application with the GraphDB triple store as its backend, and uses a subset of the RDA Registry vocabulary for its classes and properties. It runs on your own computer with Docker Compose, without any licence, or as a shared web service. It is available under the CC BY-NC 4.0 licence.

Preparing for the workshop

  • Try EntEdit. Visit the demo prototype and explore the tool yourself.
  • IFLA LRM. EntEdit follows the IFLA Library Reference Model. If it is new to you, read the description of the entities, above all Work, Expression, Manifestation, Item and Agent, and skim the relationships between them: IFLA Library Reference Model: A Conceptual Model for Bibliographic Information.
  • RDA. The elements and relationships come from the RDA Registry; you will look up relationship types there during the activities.
  • Running EntEdit yourself (optional). To run EntEdit on your own computer, install Docker and follow the setup guide before the workshop. Otherwise you can use the online version.

Activities

We will explore the tool, and discuss its use in teaching, with a selection of example datasets. In some activities you start from bibliographic descriptions only and use the tool to create the entities and add their attributes and relationships. In others we also provide a start file with basic descriptions that you can import and build on. Each activity has its own page.

  1. Cataloguing a publication

    A set of English-language novels, crime and other modern fiction, suitable as an introduction to the tool.

    No start file: catalogue your publication from scratch.

  2. Translations: Agatha Christie

    The murder of Roger Ackroyd in English, Norwegian and German: new translations, new editions and a reading of a translation, and a book that holds two novels.

    Start file: start/translations-christie.ttl · The publications only: add the works and expressions and link them.

  3. Relationships between works: Little Women

    Louisa May Alcott's novel, first published in two parts, and what has been made from it: a graphic novel, a play, an opera and a film.

    Start file: start/relationships-little-women.ttl · The publications, works and expressions, already linked: add the relationships between the works.

  4. Collections and aggregates: J. R. R. Tolkien

    The lord of the rings in boxed sets, alone or with other books, and Tolkien's shorter writings in collections with and without a title of their own.

    Start file: start/collections-tolkien.ttl · The publications and the distinct works with their expressions: link the publications to the expressions, and add the collections you consider works.

People and works carry their VIAF identifiers (http://viaf.org/viaf/…) as IRIs, so the same person or work is the same resource in every file. The activities and their sources are kept on GitHub.
