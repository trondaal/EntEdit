Ballard-*.ttl / Ballard-manifestations.ttls: J. G. Ballard, split by entity type.
Merge of the earlier catalogue sample with the isfdb2lrm conversion of ISFDB
(author 259). Persons, works and expressions that the sample identified with a
VIAF (or ISNI) identifier keep that URI; everything else uses the converter's
http://entedit.org/... identifiers. The manifestation file uses Turtle-star
(entedit:valueOrder), so load it as .ttls.
